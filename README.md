## Project objective

Build a personal, browser-first, Android Chrome compatible Local AI studio for:

1. Sanskrit and Hindi female-sounding neural voice.
2. Sanskrit pronunciation and chant recitation.
3. Singing synthesis with rhythm, pitch, duration and prosody.
4. Local audio/media analysis and music-learning memory.
5. User-controlled learning profiles and supported adaptation.
6. Personal avatar, phoneme/viseme lip-sync and body animation.
7. Captions, synchronized video composition and verified export.
8. Local storage, privacy, PWA and offline operation where technically supported.

The project has exactly four primary Indexes:

1. Workspace.
2. Voice and Chant Studio.
3. Music Learning and Training.
4. Avatar and Video Studio.

## Development rule

The first implementation milestone is a real Android Chrome Local Neural Voice proof of concept. TTS, Sanskrit pronunciation, chant, melodic singing, model training, lip-sync and video export must be tested as separate capabilities. A UI placeholder or CI success is not proof of runtime capability.
