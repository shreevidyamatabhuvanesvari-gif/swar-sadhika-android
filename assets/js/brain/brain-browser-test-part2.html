परीक्षण सुरक्षा सीमा

यह पृष्ठ केवल अपने अलग परीक्षण Database और वैकल्पिक OPFS परीक्षण फ़ाइल का उपयोग करता है। यह ऐप के Nano Server Database या मौजूदा Brain Memory Database को नहीं खोलता, बदलता या हटाता।

Browser Persistent Storage अनुमति स्वतः नहीं माँगी जाती। Quota को जानबूझकर भरने का परीक्षण नहीं किया जाता। वास्तविक Android Cold Start तभी प्रमाणित होगा जब phase=write के बाद Chrome पूरी तरह बंद करके phase=read चलाया जाए।

इस पृष्ठ का same-session close/reopen परीक्षण Chrome Process को बंद करने के बराबर नहीं है। Cross-process Cold Start के लिए अलग phase=write और phase=read प्रयोग करें। Browser Storage Permission केवल वर्तमान स्थिति के रूप में पढ़ी जाती है। Quota Exhaustion, सफल Backup Restore, वास्तविक Android Device और Strict Offline Certification इस HTML Test के दायरे में प्रमाणित नहीं होते।
